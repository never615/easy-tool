# Swoole Task 监控 Redis 连接隔离

生成时间：2026-10-11 21:18（Asia/Shanghai，UTC+08:00）。

`SWOOLE_TASK_MONITOR_REDIS_CONNECTION` 指定运输层诊断数据使用的 Laravel Redis 连接名。
未设置或为空时继续使用默认连接，不自动迁移旧计数，也不改变 enabled/mode/采样率。
以下配置可复用已经独立部署的 Horizon 统计实例：

```ini
SWOOLE_TASK_MONITOR_REDIS_CONNECTION=horizon
```

必须先确认该连接确实指向独立实例。DB编号不同不分核；同主机端口的不同逻辑连接也不分核。
Horizon会对其连接应用自身键前缀，监控保留自己的swoole_task_monitor键空间；不会改变业务队列连接。
所有写入、snapshot管理读取、reset、trace临时状态和样本都使用同一选定连接。
LaravelS、Horizon及其他写入/读取进程必须同步配置并按原部署流程重载配置缓存、重启常驻进程。
不要在新旧连接分裂状态下做Task累计量对账；切换后使用fresh基线，不拼接两个实例的计数。

此项用于监控开启时降低业务Redis竞争。生产监控默认仍关闭；不移除业务限流，
不折叠定位消息，不延迟实时位置写入，不改变Task投递、历史或报警逻辑。
隔离仍每事件写统计，并非消除统计命令；新实例的CPU/内存、错误日志仍须观测。
Redis异常继续由safeRecord隔离，监控计数是尽力而为，不能当可靠业务审计。
