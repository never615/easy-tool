# 服务器命令中心操作手册

主要读者：现场实施、运维负责人。入口：**管理端 → 配置中心 → 服务器命令**。

命令在应用的 Horizon 运维实例上运行。页面用于选择预设、修改编号、执行单条 Artisan 和查看结果；不是 SSH 终端，也不能指定任意 Web 节点。正常最多同时运行一条命令，默认 60 秒、最长 300 秒。

## 1. 发布与启用

由部署负责人先完成以下操作，现场人员日常使用不需要手工输入长命令：

1. 一起发布宿主、easy-tool、easy-location 的配套版本。宿主必须包含 `server-commands` queue connection 和 Horizon supervisor 配置，PHP CLI 可启动子进程，应用运行目录可读取 `artisan`。
2. 按原发布流程执行 `php artisan migrate --force`，创建命令执行记录/占用表，并完成定位包需要的迁移。再执行 `php artisan tool:update` 注册菜单和权限。迁移不是通过尚未启用的页面完成。
3. Web 与 Horizon 使用同一控制 PostgreSQL 数据库、Redis 队列和应用加密密钥。不要把此执行队列配置为 `sync`；不要让普通业务 worker 订阅 `server-commands`。
4. 在部署环境配置 `SERVER_COMMANDS_ENABLED=true`。这是单一全局开关，默认 `false`，不填写项目 ID 环境名单；项目范围由预设参数和账号权限决定。
5. 按现有发布流程生成配置缓存并分别重启 LaravelS、Horizon。确认 Horizon 出现 `supervisor-server-commands`，连接/队列均为 `server-commands`，每实例 1 个进程。只刷新页面不能更新常驻进程配置。
6. 授权测试账号后，在页面执行「Horizon 运行状态」和「应用环境摘要」。检查完成状态、输出、执行 hostname、角色与预期环境。按现场已安装能力选择定位诊断；只有目录提供「主动定位折叠配置检查」时才执行该项。

专用 Job 超时 330 秒、Redis 重投窗口 360 秒，CLI 上限 300 秒。这些预算独立于定位队列。多实例通过 PostgreSQL 共享占用避免并发启动；多个独立环境若错误地共用控制数据库，也会共用这一个占用。

## 2. 账号权限

在既有角色权限页面显式分配以下能力。菜单看不见时先检查「服务器命令查看」和菜单可见范围。

| 权限名称 | 用途 |
| --- | --- |
| 服务器命令查看 | 进入页面、查看本人记录 |
| 服务器预设命令执行 | 执行登记预设；定位预设仍检查项目管理范围及设备归属 |
| 任意 Artisan 命令执行 | 执行未登记命令或为预设增加其他选项，具有应用级操作能力 |
| 服务器命令全部记录查看 | 查看其他操作人的记录和输出 |
| 服务器命令故障占用恢复 | 核查进程后解除故障占用；处理他人记录还需全部记录查看 |

现有 owner 规则继续生效；其余账号不会因已有 `deploy_operations` 或普通项目管理权限而自动获得任意 Artisan 权限。任意 Artisan 包括 `tinker --execute`，可运行应用代码、修改数据或触发重启，不提供项目隔离或 PHP 沙箱。仅向承担应用级运维职责的人授予。

## 3. 常用预设

| 预设 | 参数 / 用途 |
| --- | --- |
| 主动定位折叠配置检查 | 项目编号；显示全局默认、项目继承/覆盖、最终开关、CLI 队列模式、SOS 迁移列 |
| 指定标签待算状态 | 项目编号、定位器编号；查看 source/mode/newest_at/conflict、token/pending 是否存在和 TTL，不读取原始待算数据 |
| 指定标签最近 SOS | 项目编号、定位器编号、条数；默认 3、最多 20，显示坐标和位置来源 |
| 数据库迁移状态 | 查看已执行/待执行迁移，不执行迁移 |
| Horizon 运行状态 | 当前环境 Horizon 状态 |
| Horizon 进程列表 | 已登记的 supervisor |
| 应用环境摘要 | 当前 CLI 环境摘要，不包含完整配置转储 |
| 可用 Artisan 命令 | 当前版本命令目录 |
| 应用路由概览 | 应用路由，输出较多时可能截断 |

这些预设均为按需只读查询，打开页面不会自动执行诊断。定位编号为数据库 ID，不是项目 UUID、MAC 或设备显示名称。无 SOS 记录属于正常查询结果；旧版本缺少位置来源列时，仍可查看时间和坐标，输出明确标记位置来源不可用。详细解释见[定位命令诊断手册](../../../easy-location/docs/runbooks/server-command-diagnostics.md)。

目录按已安装能力注册：当前独立发布提供 6 项通用预设和最近 SOS，共 7 项；安装主动定位折叠模块后自动增加前两项，最多 9 项。不为启用命令中心安装或开启定位折叠逻辑。

## 4. 选择执行与加载编辑

1. 搜索并选择预设，阅读说明，填写项目/定位器编号。默认项目编号仍需核对。
2. 点击「执行预设」直接提交。只读预设没有第二轮确认。
3. 需要编辑时点击「加载到编辑区」，修改编号后点「预览 / 执行」。例如：

```text
location:sos:recent --subject=123 --locator=456 --limit=3
```

已安装主动定位折叠模块的环境，也可以加载对应预设编辑项目/定位器编号；未显示该预设时，参照定位诊断手册确认能力，不把缺少模块当成执行器故障。

改变命令名或增加预设未声明的选项，会按自定义命令重新校验权限和确认。例如增加 `--env` 不再视为原来的只读预设授权。

## 5. 自定义 Artisan

在编辑区填写一条命令，可省略或填写 `php artisan` 前缀：

```text
migrate:status
php artisan help location:sos:recent
```

点击预览，核对命令、超时和请求环境，再确认执行。确认有效期 5 分钟，修改输入或超时后需重新预览。敏感选项在预览中遮蔽，请在自己的输入区核对原值。

- 不支持管道、重定向、`&&`、外层换行、多条 Shell 命令、环境变量赋值前缀或替换 PHP 程序路径。
- 空格/JSON 可放在引号内；单引号内内容原样保留，双引号内可用反斜杠转义双引号及反斜杠。不会展开变量或通配符。
- 执行器强制非交互、关闭标准输入。需要人工输入、无限运行或超过 300 秒的命令请走原终端流程。
- 不自动附加 `--force`。迁移、配置发布和重启仍应满足原操作手册的条件；页面不会替代停流、排空或备份流程。
- `--env` 只传给子命令，不切换服务器，也不改变命令中心记录所在的控制数据库。缓存配置或继承环境可能使它不能切换到预期配置，不能仅凭请求值确认生效。

## 6. 查看结果及执行位置

从最近 20 条记录选择「查看」。运行时轮询摘要，结束后展示有界 stdout/stderr；输出以纯文本显示，合计最多保存 256 KiB，超限显示截断。关闭页面不会取消命令；网络异常时先刷新记录，核对原执行，勿重新创建同一操作。

| 状态 | 处理方式 |
| --- | --- |
| 待执行 | 检查开关是否已在 Horizon 生效、专用 supervisor 是否在线、Redis 连接是否一致 |
| 运行中 | 等待结果；超过执行端回报期限后页面会标记未知，仍保留占用 |
| 命令完成 | 退出码 0；若命令派生 Job 或触发重启，仍需按相应手册验证后续结果 |
| 非零退出 | 阅读错误输出，确认副作用后再决定是否重新创建执行 |
| 未启动 | 启动前权限/命令定义校验失败，或 CLI 无法创建；修复后重新预览 |
| 超时 / 结果未知 | 不自动重跑，不自动解锁；按下一节核对 |
| 已人工解除占用 | 只代表运维解除占用，不表示原命令成功或副作用回滚 |

页面节点是接待 HTTP 的 Web 实例；执行节点显示在执行记录中。记录中的 `environment` 是父执行器部署环境；`--env` 是对子 CLI 的请求，不宣称是子 CLI 实际加载值。定位预设自身输出的 `scope.environment` 来自该次 CLI。

Kubernetes 中 Web 和 Horizon 可以是不同 Pod，`bootstrap/cache`、`storage/framework` 不一定共享。在 Horizon 实例运行 `config:cache` 不能证明 Web Pod 的缓存已改变；重启或配置发布需按原部署流程验证全部目标实例。

## 7. 超时、未知与故障占用

1. 记录执行编号、实际 hostname、worker PID、CLI PID、开始时间和输出。队列投递异常也可能显示未知，不能当作从未执行。
2. 通过原服务器/容器运维入口核查该实例。核实旧 CLI、它可能创建的子进程/异步工作已停止，核对已经产生的数据变化；必要时按原部署流程重启执行实例。PID 会复用，须同时核对实例和开始时间。
3. 具备恢复权限的人打开该记录，输入 **已确认进程停止**，点击「解除本次故障占用」。这一动作不负责停止进程、不回滚数据，也不重放命令。
4. 解除后旧队列消息不能再次启动原执行。确需重做时，先核查结果，再创建新执行。

超时不等于事务回滚或全部派生进程结束。不要直接清空占用表或重试失败队列来恢复。数据库、Redis 或后台本身不可用时，使用原终端救援入口；系统不会回退到 Web Worker 同步运行。

## 8. 保留与停用

参数和输出加密存储，已知敏感值尽力遮蔽；任意输出仍可能包含敏感业务内容，按运维资料管理。队列消息仅含执行编号，命令接口不进入通用完整请求/响应日志。

每日 04:20 清理：已结束正文默认保留 7 天，摘要 90 天，每次最多处理 500 条；依赖现有 scheduler。未知、超时及未结束记录不自动删除。需要人工补跑时使用短命令 `php artisan tool:server-commands:prune`。密钥轮换需遵循原应用加密密钥兼容流程，否则旧正文可能无法读取。

停用顺序：先让 Web 端 `SERVER_COMMANDS_ENABLED=false` 生效以停止新提交；查看并等待已有命令收尾，未知占用人工核查；最后按发布流程关闭并重建 Horizon，撤去专用 supervisor。停用按钮不终止已运行命令，历史记录仍可查看。回滚代码前保留执行表；有占用时迁移回滚会拒绝删除。
